# Career Quest — черновой интерактивный прототип

Локальный макет для знакомства с продуктом. Работают выбор сотрудника и цели, рекомендации по правилам, объяснения, симуляция завершения активности, пересчёт навыков, история и обзор HR.

## Запуск

Из корня репозитория, Node.js 22+:

```sh
node scripts/serve.mjs
```

Открыть http://127.0.0.1:4173. Пакеты устанавливать не нужно.

Подготовленный синтетический снимок `src/prototype/data.json` уже включён в командный репозиторий. При получении обновлённого набора его можно пересобрать:

```sh
python3 scripts/prepare-demo-data.py --source /path/to/career_quest_dataset
```

Команда не изменяет набор организаторов. Сервер публикует только каталог прототипа и слушает localhost: `.env.local` и прочие файлы репозитория недоступны через него.

## Что попробовать

1. Открыть причины рекомендации и пройти активность в демо: прогресс должен измениться, повторное начисление недоступно.
2. Выбрать другого сотрудника, включая профиль без цели или со сменой роли.
3. Изменить цель и сравнить рекомендации.
4. Переключиться на обзор HR и открыть профиль из списка без следующего шага.
5. Нажать «Сбросить демо» для восстановления исходного состояния.
6. После настройки AI нажать «Подобрать с AI», затем «Почему мне?» и «Сравнить с подбором по правилам». При изменении цели или прохождении активности в AI-режиме подбор обновляется.

## Ограничения

- Это **не полное решение хакатона**: импорт дополнительных профилей, авторизация и постоянное хранение ещё не реализованы.
- Базовый подбор детерминирован: фильтры роли/грейда, prerequisites, дат, истории; рейтинг по сокращению пробелов, приоритету критичных навыков, длительности и истории формата. AI по запросу выбирает среди всех допустимых кандидатов и объясняет выбор. [Настройка и оценка](../../docs/ai-recommendations.md).
- Отсутствующая цель заменяется явно обозначенной предполагаемой целью. Для Lead используется текущая роль и грейд. Смена цели не отменяет допуск по текущей роли/грейду.
- Балл прогресса = сумма покрытых требуемых уровней / сумма требуемых уровней. Это не обещание повышения.
- Последующие завершения применяются после `last_review_date`. Для самостоятельных курсов дата зачисления используется как приближение даты завершения; в исходнике нет `completed_at`. Подробнее: `docs/career-quest-data-review.md`.
- Новое завершение моделируется сразу, даже если сессия в будущем. Действие помечено «Пройти в демо», не меняет реальные записи и работает один раз на мероприятие в текущей сессии.
- Прогресс и выбранные цели хранятся только в памяти страницы. Обновление страницы сбрасывает их. HR-режим доступен открыто, только для демонстрации синтетических данных.
- При выключенном AI внешних запросов нет. После явного включения и подтверждения разрешённого использования данных сервер передаёт модели роль, грейд, цель, допустимые активности и агрегаты истории форматов без ФИО. Ресурсы интерфейса локальные.
- Старый `python3 scripts/preview.py` по-прежнему запускает только статический режим, без AI API.
