# Проверки продукта

После выбора сценария проверяем успешный результат, некорректный ввод и недоступность внешнего сервиса.
Для AI подготавливаем небольшой набор примеров с ожидаемыми свойствами результата.
Повторяемые автоматические проверки по умолчанию не должны требовать платных API-вызовов.
Для чернового прототипа добавлены проверки на встроенном тестовом модуле Node.js (Node 22+):

```sh
node --test --test-isolation=none tests/prototype.test.mjs tests/ai.test.mjs tests/development.test.mjs tests/import.test.mjs
```

Проверяются допуск к рекомендациям по всем 200 профилям, повторяемость, обновление навыков без двойного начисления, изменение цели и ограничения уровня навыка.
Дополнительно проверяются последовательные маршруты, prerequisites и расписание, фокус и недельная нагрузка, HR-черновики и длительность программы, ключ как единственная настройка, горячее перечитывание конфигурации и сохранение прогресса.

AI-проверки используют тестовый транспорт без внешних запросов: формат Responses,
проверка фактов и допустимости, резервный режим, таймаут, кеш, согласованность
состояния браузера и сервера, поздние ответы и HTTP API. Они не измеряют качество
реальной модели. Для сравнительного отчёта: `node scripts/evaluate-ai.mjs`, а после
настройки провайдера — `node scripts/evaluate-ai.mjs --live`.

31 тест, без внешних вызовов. Новые проверки охватывают импорт, CSV, конфликты ID, атомарное применение, версии, отмену после перезапуска, единый набор браузера/AI, подготовку по навыкам вне цели и обновление мастерской HR с текущим демо-прогрессом.

Три AI-сценария: `node scripts/check-ai-workflows.mjs` (без модели), `node scripts/check-ai-workflows.mjs --live` (ровно три реальных запроса на вымышленных данных, нужен ключ). Отчёт содержит liveVerified и явно различает ответы AI и расчёты по правилам.
