# Проверки продукта

После выбора сценария проверяем успешный результат, некорректный ввод и недоступность внешнего сервиса.
Для AI подготавливаем небольшой набор примеров с ожидаемыми свойствами результата.
Повторяемые автоматические проверки по умолчанию не должны требовать платных API-вызовов.
Для чернового прототипа добавлены проверки на встроенном тестовом модуле Node.js (Node 20+):

```sh
node --test --test-isolation=none tests/prototype.test.mjs tests/ai.test.mjs
```

Проверяются допуск к рекомендациям по всем 200 профилям, повторяемость, обновление навыков без двойного начисления, изменение цели и ограничения уровня навыка.

AI-проверки используют тестовый транспорт без внешних запросов: формат Responses,
проверка фактов и допустимости, резервный режим, таймаут, кеш, согласованность
состояния браузера и сервера, поздние ответы и HTTP API. Они не измеряют качество
реальной модели. Для сравнительного отчёта: `node scripts/evaluate-ai.mjs`, а после
настройки провайдера — `node scripts/evaluate-ai.mjs --live`.
