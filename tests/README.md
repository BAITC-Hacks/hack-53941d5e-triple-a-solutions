# Проверки продукта

После выбора сценария проверяем успешный результат, некорректный ввод и недоступность внешнего сервиса.
Для AI подготавливаем небольшой набор примеров с ожидаемыми свойствами результата.
Повторяемые автоматические проверки по умолчанию не должны требовать платных API-вызовов.
Для чернового прототипа добавлены проверки на встроенном тестовом модуле Node.js (Node 20+):

```sh
node --test tests/prototype.test.mjs
```

Проверяются допуск к рекомендациям по всем 200 профилям, повторяемость, обновление навыков без двойного начисления, изменение цели и ограничения уровня навыка.

## Backend

Node.js 24+: npm test запускает исходные тесты и tests/backend.test.mjs. Покрыты валидация, начисления по сессиям, отсутствие повторного зачёта, конкурентные запросы, перезапуск базы, права HR и атомарный импорт. Временные SQLite-базы создаются только для тестов.

## Проверки объединения веток

`npm test` также запускает `ai.test.mjs`, `development.test.mjs`, `integration.test.mjs`: fallback, строгие AI-схемы, карты развития, HR-черновики, авторизация новых маршрутов, неизменность порядка рекомендаций и использование сохранённых уровней. Провайдеры в тестах отключены или заменены фикстурами; внешних запросов нет.
