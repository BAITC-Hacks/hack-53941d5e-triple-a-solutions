# Примеры для демо

Добавляйте синтетические или разрешённые к публикации входные данные.
Для каждого примера укажите происхождение, ожидаемый результат и критерий успеха.
Рабочие приватные данные держите в игнорируемом `data/private/`.

## Примеры импорта Career Quest

`jury-employees.json` и `jury-history.csv` — вымышленные записи для совместной загрузки через экран «Данные жюри». Они используют ID навыков и активностей текущего каталога. [Инструкция](../../docs/jury-import.md). Это не реальные данные жюри.
