# Triple A Solutions — Career Quest

Рабочая папка для HackAlem AI, 23 сентября 2026, Астана.
Добавлен черновой интерактивный прототип Career Quest на датасете организаторов.
Это макет для знакомства с продуктом. Добавлен серверный AI-подбор с проверкой ответа и резервным подбором по правилам. Реальное качество AI требует проверки с выбранной моделью; импорт профилей и истории доступен с предпросмотром и отменой. Авторизация пока не реализована.

## Последняя версия для команды

Версия с AI-помощниками, картой развития, мастерской HR и импортом жюри находится
в ветке **codex/employee-navigator**: [открыть эту ветку](https://github.com/BAITC-Hacks/hack-53941d5e-triple-a-solutions/tree/codex/employee-navigator).
Обсуждение изменений — [черновик PR №2](https://github.com/BAITC-Hacks/hack-53941d5e-triple-a-solutions/pull/2).

Для просмотра без Git: откройте ссылку на ветку → **Code → Download ZIP**, распакуйте
архив и запустите `start-prototype.cmd` на Windows или `node scripts/serve.mjs`
на macOS/Linux. Нужен Node.js 22+. Затем откройте http://127.0.0.1:4173
**на своём ноутбуке** и оставьте окно сервера открытым.

Интерфейс и расчёты запускаются без ключа. Для ответов AI на другом ноутбуке нужно
локально заполнить `.env.local`; ключ автора в GitHub и ZIP не передаётся.
[Подробная инструкция для команды](docs/team-preview.md).

## Открыть прототип Career Quest

Из корня репозитория, Node.js 22+ (без установки пакетов):

```sh
node scripts/serve.mjs
```

Откройте http://127.0.0.1:4173. Зависимости устанавливать не нужно.
На Windows можно дважды открыть `start-prototype.cmd` (использует установленный Node.js или runtime Codex).
В репозитории уже есть подготовленный синтетический снимок данных для запуска.
Команда `python3 scripts/prepare-demo-data.py --source /path/to/career_quest_dataset` нужна, только если организаторы выдадут обновлённый набор.
Подробнее: [описание прототипа](src/prototype/README.md).

Работают карта развития с последовательными квестами и мастерская HR для улучшения активностей. Без ключа доступны расчёты и черновики по правилам. Для подключения AI заполните `OPENAI_API_KEY` в `.env.local` и обновите страницу. Модель и endpoint настроены, но доступ к модели, квота и реальные ответы требуют проверки. [Инструкция и ограничения](docs/ai-recommendations.md). Ключ хранится только на сервере.

В разделе **Данные жюри** можно импортировать JSON-профили и CSV/JSON-историю: проверка → предпросмотр → применение → отмена. [Формат и примеры](docs/jury-import.md). Исходные файлы не меняются; браузер и AI-сервер используют один набор.

Для первой проверки AI на Windows: [добавьте ключ по инструкции](docs/connect-ai.md), затем запустите `check-ai.cmd` двойным щелчком. Проверяются все три функции на вымышленных данных.

## Начать работу

```sh
git clone --branch codex/employee-navigator https://github.com/BAITC-Hacks/hack-53941d5e-triple-a-solutions.git
cd hack-53941d5e-triple-a-solutions
```

Если `.env.local` ещё нет, скопируйте `.env.example` в `.env.local` и заполните нужные ключи локально. Не перезаписывайте существующий файл.
Для проверки каркаса нужен Python 3.10+:

```sh
python3 scripts/check_repo.py
```

На подготовленном Mac локальные Node.js и GitHub CLI доступны через:

```zsh
source scripts/use-hackalem-tools.zsh
```

Каталог `.tools/` не входит в Git. На других компьютерах используйте свои установленные инструменты.
Прототип использует HTML/CSS/JavaScript без сборки. Стек полного решения пока не зафиксирован.

## Совместная работа

Сначала заполните `docs/brief.md`, затем распределите задачи в `docs/plan.md`.
Делайте небольшие коммиты с законченным изменением. Для задач используйте ветки `codex/<task>` или согласованный командой префикс.
Перед коммитом выполните проверку и просмотрите `git diff` / `git diff --cached`.
Не добавляйте ключи, приватные данные и локальные инструменты. Локальная копия `unfairgaps-os/` исключена из Git.

После подготовки коммита отправка текущей ветки:

```sh
git push -u origin HEAD
```

## Готовность MVP

- Один пользователь проходит основной сценарий от входных данных до полезного результата.
- Для результата есть проверка качества и сравнение с исходным способом решения.
- Реальные вызовы AI и демонстрационные заглушки явно различимы.
- Проект воспроизводимо запускается по README; демо проверено с чистого старта.
- Комплект сдачи соответствует полученному регламенту.
