## Начать работу

```sh
git clone https://github.com/mxwqs/hackalem-ai.git
cd hackalem-ai
```

Если `.env.local` ещё нет, скопируйте `.env.example` в `.env.local` и заполните нужные ключи локально. Не перезаписывайте существующий файл.
Для проверки каркаса нужен Python 3.10+:

```sh
python3 scripts/check_repo.py
```

На подготовленном Mac локальные Node.js и GitHub CLI доступны через:

```zsh
source scripts/use-hackalem-tools.zsh
```

Каталог `.tools/` не входит в Git. На других компьютерах используйте свои установленные инструменты.
Команды установки и запуска приложения добавим после выбора стека.

## Совместная работа

Сначала заполните `docs/brief.md`, затем распределите задачи в `docs/plan.md`.
Делайте небольшие коммиты с законченным изменением. Для задач используйте ветки `codex/<task>` или согласованный командой префикс.
Перед коммитом выполните проверку и просмотрите `git diff` / `git diff --cached`.
Не добавляйте ключи, приватные данные и локальные инструменты. Локальная копия `unfairgaps-os/` исключена из Git.

После подготовки коммита отправка текущей ветки:

```sh
git push -u origin HEAD
```

## Готовность MVP

- Один пользователь проходит основной сценарий от входных данных до полезного результата.
- Для результата есть проверка качества и сравнение с исходным способом решения.
- Реальные вызовы AI и демонстрационные заглушки явно различимы.
- Проект воспроизводимо запускается по README; демо проверено с чистого старта.
- Комплект сдачи соответствует полученному регламенту.
