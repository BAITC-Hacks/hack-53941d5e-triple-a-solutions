# Демо и сдача

Продолжительность и состав сдачи уточняются у организаторов.

## Черновой сценарий на 3 минуты

1. 0:00–0:30 — конкретный пользователь, проблема и исходный способ решения.
2. 0:30–1:45 — один живой сценарий: вход → действия системы → результат.
3. 1:45–2:15 — проверка результата и измеренная польза на примерах.
4. 2:15–2:45 — как работает AI, инструменты и обработка ошибок.
5. 2:45–3:00 — ограничения MVP и следующий шаг.

## Перед сдачей

- [ ] Сопоставить реализацию со всеми официальными критериями.
- [ ] Проверить запуск по README с чистого состояния.
- [ ] Проверить основной сценарий и сбой внешнего сервиса.
- [ ] Подготовить разрешённые примеры и явно обозначенный резервный показ.
- [ ] Указать реальные ограничения и отличать mock от live.
- [ ] Проверить доступ жюри к репозиторию и демо.
- [ ] Вписать итоговый commit SHA, ссылки и инструкцию запуска.
- [ ] Отправить требуемый комплект до подтверждённого дедлайна.

Итоговый commit: не выбран. Демо URL: не создан. Отправка: не выполнена.
