# Открыть последнюю версию на ноутбуке напарника

Изменения находятся в ветке **codex/employee-navigator**. Открытие основной ветки
`main` может показать другую версию. PR №2 остаётся черновиком для командной проверки.

## Быстро посмотреть без Git

1. Войдите в GitHub аккаунтом, которому доступен командный репозиторий.
2. Откройте [нужную ветку](https://github.com/BAITC-Hacks/hack-53941d5e-triple-a-solutions/tree/codex/employee-navigator).
3. Нажмите **Code → Download ZIP** и распакуйте архив в отдельную папку.
4. На Windows дважды запустите **start-prototype.cmd** из Проводника.
   Нужен Node.js 22+; скрипт также умеет использовать локальный runtime Codex, если он есть.
   На macOS/Linux откройте терминал в распакованной папке и выполните:

   ```sh
   node scripts/serve.mjs
   ```

5. Дождитесь строки `Career Quest: http://127.0.0.1:4173` и откройте этот адрес
   в браузере на том же ноутбуке. Окно сервера оставьте открытым.

`127.0.0.1` у каждого компьютера свой: ссылка не подключает напарника к серверу
на чужом ноутбуке. На каждом ноутбуке запускается своя копия.
Если порт занят, закройте прежний сервер этого прототипа или запустите
`node scripts/serve.mjs --port 4174` и откройте http://127.0.0.1:4174.

## Если планируете редактировать код

В терминале, из папки для проектов:

```sh
git clone --branch codex/employee-navigator https://github.com/BAITC-Hacks/hack-53941d5e-triple-a-solutions.git
cd hack-53941d5e-triple-a-solutions
node scripts/serve.mjs
```

Если репозиторий уже клонирован, сначала проверьте `git status`. При наличии своих
изменений сохраните их в своей ветке/коммите. На чистой рабочей копии:

```sh
git fetch origin
git switch codex/employee-navigator
git pull --ff-only origin codex/employee-navigator
```

Если `pull --ff-only` сообщает о расхождении веток, остановитесь и согласуйте
объединение с командой. Не используйте принудительную отправку или сброс изменений.
Для собственной работы создайте отдельную ветку от полученной версии и отправляйте
изменения через PR. ZIP подходит для просмотра; для совместной разработки используйте Git.

## AI на другом ноутбуке

Без ключа работают интерфейс, импорт, расчёты маршрута и шаблон предложений HR.
Файл автора `.env.local` не входит в Git и ZIP. Для настоящих ответов модели
скопируйте `.env.example` в `.env.local` (если файла ещё нет), добавьте ключ своего
разрешённого проекта и следуйте [инструкции подключения](connect-ai.md).
Проверка на вымышленных данных: `check-ai.cmd` на Windows или
`node scripts/check-ai-workflows.mjs --live` на macOS/Linux. Это до трёх платных вызовов.

На одном подключении все три функции уже получили реальные ответы gpt-4.1-mini;
есть выявленные недочёты формулировок. [Результаты и ограничения проверки](ai-live-check-2026-09-23.md).

## Что посмотреть

- **Мой рост:** выбрать сотрудника и цель, создать план, завершить шаг в демо.
- **Мастерская HR:** выбрать активность, получить черновик, изменить и сохранить его.
- **Данные жюри:** вместе загрузить `data/examples/jury-employees.json` и
  `data/examples/jury-history.csv`, проверить, применить и отменить импорт.

Цели и черновики сохраняются в браузере, импорты — локально на ноутбуке.
Git синхронизирует код; общая база прогресса сотрудников пока не реализована.
