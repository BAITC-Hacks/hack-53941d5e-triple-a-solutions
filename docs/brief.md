# Задание и MVP

Статус: ожидаем официальное задание.

| Поле | Значение |
| --- | --- |
| Кейс / трек / источник | Не получены |
| Дедлайн и часовой пояс | Не подтверждены |
| Лимит работы | Пять часов после объявления задания, со слов пользователя; отсчёт ещё не начался |
| Команда | Три участника, начальный уровень разработки |
| Формат сдачи | Не подтверждён |
| Пользователь и его задача | Не выбраны |
| Как решается сегодня | Не исследовано |
| Входные данные и разрешения | Не определены |
| Полезный результат | Не определён |
| Роль AI и инструментов | Не определена |
| Метрика успеха и исходный уровень | Не определены |
| Обязательные ограничения | Не получены |
| Что входит в MVP | Не выбрано |
| Что отложено | Не выбрано |

## Матрица требований

После объявления заполнить: требование → источник → реализация → способ проверки → ответственный.

## Основной сценарий

1. Пользователь предоставляет: …
2. Система выполняет: …
3. Пользователь получает: …
4. Успех проверяется по: …

## Риски, которые нужно проверить первыми

Доступ к данным; работоспособность обязательной интеграции; возможность проверить результат; оставшееся время.
