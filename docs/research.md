# Исследование проблемы

[UnfairGaps](https://github.com/AyanbekDos/unfairgaps-os) установлен в локальный каталог навыков Codex. Клон `unfairgaps-os/` служит справочником и не включён в этот репозиторий.

После получения темы выбираем подходящую операцию: `industry-scan` для отрасли и страны; `validate-idea` для идеи и страны; `profession-scan` для профессии и страны. Для исследования сайта есть `site-audit` и `customer-pains`.

UnfairGaps полезен для поиска подтверждённых проблем. Он не заменяет регламент HackAlem и не нужен для каждого возможного кейса. Полный протокол применяем, только если тема и оставшееся время позволяют; сокращённую проверку не называем полным отчётом UnfairGaps.

Результаты исследования хранить здесь со ссылками, датами и явным разделением фактов и гипотез. Финансовые и правовые утверждения из примеров репозитория требуют проверки по актуальным первичным источникам.
