# Команда и решения

## Команда

| Участник | Навыки | Ответственность |
| --- | --- | --- |
| Участник 1 (владелец репозитория) | Базовое понимание разработки | Предлагается: работа с Codex, запуск и интеграция |
| Участник 2 | Начальный уровень | Предлагается: разбор кейса, подготовка примеров, ручная проверка |
| Участник 3 | Начальный уровень | Предлагается: сценарий демо, материалы, проверка понятности интерфейса |

Подтверждено пользователем: три участника, без уверенного опыта разработки; на работу пять часов. Роли — предложение, имена и назначения нужно согласовать внутри команды. Codex помогает с реализацией и техническими проверками.
